# Brand assets

Flat isometric marks in the Hyperdrive palette: navy `#0f1b2d`, cyan `#18bae6`, amber `#f5a524`,
light `#f4f4f4`. SVG sources with 512 px / 1280×640 PNG renders
(`magick -background none -density 192 X.svg -resize WxH X.png`).

| File | Use |
| --- | --- |
| `org-avatar.png` | GitHub organization avatar |
| `hyperdrive-mark.*`, `holodeck-mark.*` | Product marks |
| `social-core.png`, `social-holodeck.png`, `social-holodeck-sdk.png` | Repository social previews (Settings → Social preview) |

GitHub has no API for avatars or social previews, so upload these by hand.
