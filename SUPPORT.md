# Support

For setup questions, usage help and design discussions, use the public repos'
Discussions:

- [Holodeck Discussions](https://github.com/hyperdrive-technology/holodeck/discussions)
- [Holodeck SDK Discussions](https://github.com/hyperdrive-technology/holodeck-sdk/discussions)

Include the repository, commit or version, what you tried, and relevant output.
Check its README and CONTRIBUTING guide first. If Discussions is unavailable,
open an issue asking where to get help.

For reproducible bugs, search existing issues and then use the bug report form
in [Holodeck](https://github.com/hyperdrive-technology/holodeck/issues/new/choose)
or the [SDK](https://github.com/hyperdrive-technology/holodeck-sdk/issues/new/choose).
Use the feature request form for proposed behaviour and the task form for
scoped implementation work. Core is private for now; contributors with access
can use [core issues](https://github.com/hyperdrive-technology/core/issues/new/choose).
Keep private core details in that repository.

Report vulnerabilities using [SECURITY.md](SECURITY.md), and conduct concerns
using [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Maintainer:
[@DezLitz](https://github.com/DezLitz).
